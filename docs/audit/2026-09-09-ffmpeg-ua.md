# Browser UA untuk ffmpeg (2026-09-09)

## Root cause (terbukti empiris)
Batch flickreels 403 massal: token verify masih valid ±1 jam (bukan
expiry). Tes ffprobe terkontrol: tanpa UA / UA "Mozilla/5.0" saja -> 403;
full Chrome UA -> sukses (durasi terbaca). CDN (farsunpteltd dkk) block
UA default ffmpeg (Lavf) maupun UA terpotong.

## Perubahan
- `downloader.js downloadStream`: `-headers User-Agent: Mozilla/5.0`
  -> full Chrome UA (const BROWSER_UA, string sama dgn axios repo).
- `vidaraService.js ensureMp4`: tambah `-user_agent` full UA (sebelumnya
  tanpa UA sama sekali).
- `getVideoInfo` TIDAK diubah (koreksi proposal): verifikasi menunjukkan
  ia hanya probe file LOKAL, tak pernah kena CDN.
